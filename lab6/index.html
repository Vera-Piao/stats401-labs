Design Description

Comparing Treemap Segmentation Methods

Both treemaps encode GDP using rectangle area and GDP status using color, so the main difference between them is the spatial subdivision method. The squarified treemap attempts to create rectangles with more balanced aspect ratios, which makes many countries easier to label and supports visual comparison of GDP across countries. In contrast, the binary treemap recursively divides the available space into two groups. This produces a more structured partition but can create long or narrow rectangles, especially for countries with smaller GDP values, making labels and area comparisons more difficult. In both layouts, large economies such as the United States and China are immediately visible because they occupy substantially larger areas. Color provides a consistent secondary encoding of GDP status across both layouts. Overall, the comparison demonstrates that the segmentation method changes the spatial organization and readability of the hierarchy even when the underlying hierarchical data and visual encodings remain the same.
