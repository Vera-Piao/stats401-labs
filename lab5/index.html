Interactive Network Visualization

An interactive analysis of an urban transit network using a force-directed node-link diagram and an adjacency matrix.

Dataset Description

Urban Transit Network

The dataset represents an undirected urban transit network containing 50 stations and 50 direct connections. Station attributes include district, daily passenger volume, and station type. Route attributes include direct travel time and route type.

Node-Link Visualization

Force-Directed Transit Network

Hover over a station to inspect its attributes and highlight its direct connections. Drag stations to explore the network layout.

Design Description

Node-Link Design

In the node-link visualization, district is encoded by node color, daily passenger volume by node size, and station type by node shape. These encodings make it possible to compare station characteristics while preserving the overall network topology. Route type is encoded by link color, while direct travel time is represented by link width, with thicker links indicating longer travel times. The force-directed layout separates stations while keeping directly connected stations linked, making local connectivity patterns easier to inspect. Interaction further supports exploration: stations can be dragged to adjust the layout, hovering over a station highlights its direct neighbors and connections, and tooltips provide exact station and route attributes.

Adjacency Matrix

Transit Connections by Station

Cell color represents route type, while cell opacity represents travel time. Darker cells indicate longer travel times. Gray cells indicate no direct connection. Stations are ordered by district, then station name.

Design Description

Adjacency Matrix Design

The adjacency matrix represents the same network by placing the 50 stations on both the rows and columns, with colored cells indicating direct connections between station pairs. Route type is encoded by cell color, while travel time is encoded by opacity, with darker cells representing longer direct travel times. Because the transit network is undirected, the matrix is symmetric across the main diagonal. Stations are ordered first by district and then by station name, which groups stations from the same district together and makes patterns of within-district and between-district connectivity easier to examine. Hovering over a connected cell identifies the two stations and displays the exact route type and travel time.

Network Questions

Network Questions and Findings

1. Which stations appear central in the network?

Partially. Node-link visualization. The links and hover highlighting make stations with multiple direct neighbors easier to identify. However, the network does not contain one dominant hub. Several stations, including Stations 4, 7, 10, 13, and 16, each have three direct connections, which is the highest degree observed in the network.

2. Which districts are strongly connected to one another?

Well. Adjacency matrix. Ordering stations by district makes connections between district groups easier to identify as patterns of colored cells. East and South are the most strongly connected pair, with 11 direct connections. Central and North, as well as East and West, are also strongly connected, with 9 direct connections each.

3. Where are transfer or terminal stations located in the topology?

Well. Node-link visualization. Node shape distinguishes Local, Transfer, and Terminal stations, making the locations of special station types visible across the topology. Transfer and Terminal stations are distributed throughout the network rather than occupying a single region. Some Terminal stations, including Stations 43, 46, and 49, are isolated with no direct connections.

4. Which stations have high passenger volume?

Well. Node-link visualization. Daily passenger volume is encoded by node size, so high-volume stations appear as larger nodes. Station 50 has the highest passenger volume at 9,850 daily passengers, followed by Station 49 with 9,677 and Station 48 with 9,604.

5. Where are the longest direct travel-time connections?

Well. Both visualizations. Longer travel times appear as thicker links in the node-link diagram and as darker connected cells in the adjacency matrix. Tooltips provide the exact travel time for individual connections. The longest direct connection is between Station 7 and Station 31 at 16 minutes, followed by Station 18 and Station 34 at 15 minutes and Station 29 and Station 50 at 14 minutes.

6. Are particular route types concentrated in particular parts of the network?

Partially. Both visualizations. Route type is encoded by color in both links and matrix cells, while the matrix ordering helps reveal its distribution across districts. Route types are not exclusively concentrated in a single part of the network, although some local patterns are visible. Metro has four East-South connections, Express has four Central-North and four East-West connections, and Shuttle has four East-South connections.
