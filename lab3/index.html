Lab 3 Assignment

Overwatch 2 Hero Competitive Statistics

Competitive hero statistics across regions and competitive divisions on PC.

This dataset was acquired programmatically from the OverFast API using Python and the requests library.

Each row represents one Overwatch 2 hero in a specific region and competitive division. The dataset contains 1,113 records and includes hero name, region, competitive division, pick rate, win rate, and ban rate.

Click any column heading to sort the table in ascending or descending order.
